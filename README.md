# NOEL PRISM

ノエルと遊ぶ、全10ステージのブロック崩し。

## 遊ぶ

GitHub Pagesを有効にすると、ブラウザでURLを開くだけで遊べます。プレイヤーのGitHubログインは不要です。

- 移動：マウス / ← → / A D / タッチ
- 発射・再発射：クリック / Space / 発射ボタン
- 一時停止：Esc / P
- レア技：E / 「スキル発動」ボタン

通常アイテムはパドル拡大・マルチボール・スロー・キャッチ。レア技はノエルの底面ガード＋5ボール、ビーム、貫通の3種類。レア技は1つだけストックできます。

ノエルのドット絵は通常10パターン＋ガーディアン用の横たわるポーズ。鑑賞画面もあります。

セーブとランキングは各プレイヤーのブラウザ内に保存します。プレイヤー同士の記録を共有するオンラインランキングはありません。

## GitHub Pagesの設定

Settings → Pages → Build and deploymentで、Sourceを「Deploy from a branch」、Branchを「main」、Folderを「/(root)」にしてSaveします。

起動ファイルはリポジトリ直下の `index.html` です。ビルドや外部サービスの設定は不要です。

## 素材

キャラクター参考資料を元に、画像生成ツールで制作したドット絵を使用しています。
